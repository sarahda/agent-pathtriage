# Responsible Use

AgentPathTriage is a security-research project. It contains proof-of-concept exploit scripts and an intentionally vulnerable lab environment, intended to help defenders understand and mitigate cross-agent IAM privilege escalation in managed agentic cloud platforms.

## Intended use

- Security research, education, and defensive improvement.
- Reproduction **only** within cloud accounts and tenants that you own or are explicitly authorised to test.

## Prohibited use

- Use against any system, account, or tenant you do not own or lack authorisation to test.
- Any activity that violates applicable law or the terms of service of AWS, Microsoft, or any other provider.

## Evaluation data

Any prevalence study in this project analyses **only publicly published configuration templates**, statically, from their published artefacts. No live third-party deployment is probed, scanned, or accessed.

## Coordinated disclosure

If a publicly published template belonging to an identifiable party is found to ship an exploitable default, coordinated disclosure will be initiated **before publication**, following a 90-day standard. Identifying details are withheld until disclosure completes.
